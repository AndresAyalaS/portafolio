# 💼 Portafolio de Andres Ayala

Portafolio personal desarrollado con Next.js 14, TypeScript y Tailwind CSS. Muestra mi experiencia como Desarrollador FullStack especializado en Angular, React, .NET y Java Spring Boot.

## 🚀 Tecnologías

- **Framework:** Next.js 14 (App Router)
- **Lenguaje:** TypeScript
- **Estilos:** Tailwind CSS
- **Animaciones:** Framer Motion
- **Partículas:** TSParticles
- **Fuente:** Urbanist (Google Fonts)
- **Deployment:** Netlify

## ✨ Características

- ✅ SEO optimizado con metadata completa
- ✅ Open Graph y Twitter Cards
- ✅ Sitemap y robots.txt automáticos
- ✅ Imágenes optimizadas con Next.js Image
- ✅ Animaciones fluidas con Framer Motion
- ✅ Diseño responsive
- ✅ Accesibilidad (a11y) mejorada
- ✅ Headers de seguridad configurados
- ✅ Loading states y error boundaries
- ✅ Performance optimizada


## 📁 Estructura del Proyecto

```
├── app/
│   ├── (routes)/        # Rutas de la aplicación
│   ├── layout.tsx       # Layout principal
│   ├── page.tsx         # Página de inicio
│   ├── loading.tsx      # Estado de carga
│   ├── error.tsx        # Página de error
│   ├── not-found.tsx    # Página 404
│   └── sitemap.ts       # Sitemap automático
├── components/          # Componentes reutilizables
├── public/             # Archivos estáticos
├── utils/              # Utilidades y helpers
└── data.tsx            # Datos del portafolio
```

## 🌐 Deployment en Netlify

Este proyecto está configurado para desplegarse automáticamente en Netlify:

1. Conecta tu repositorio de GitHub a Netlify
2. Netlify detectará automáticamente la configuración de Next.js
3. Las variables de entorno se configuran en el panel de Netlify
4. Cada push a `main` despliega automáticamente


## 🎨 Personalización

### Colores

Los colores principales se pueden modificar en `tailwind.config.ts`:

```typescript
colors: {
  secondary: "#f5741c",  // Color de acento
  darkBg: "#131424",     // Fondo oscuro
}
```
